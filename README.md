## 🎯 What Is FTRIYANA?

</div>

<table align="center">
<tr>
<td width="50%" valign="top">

### 💀 The Problem

- ❌ Manual recon is slow
- ❌ 70+ tools to remember
- ❌ No AI analysis
- ❌ Results scattered everywhere
- ❌ Copy-paste chaos

</td>
<td width="50%" valign="top">

### ⚡ The Solution

- ✅ **AI-powered shell**
- ✅ **70+ tools orchestrated**
- ✅ **Smart planning**
- ✅ **JSON reports**
- ✅ **One command, full recon**

</td>
</tr>
</table>

<div align="center">

**FTRIYANA** is an **AI-driven pentesting framework** that combines 70+ security tools with an **AI client** that plans attacks, analyzes results, and suggests next steps. **It's recon on autopilot.**

<br/>

> *"Stop running tools manually. Let AI drive your recon."*

</div>

## 🏗️ Architecture

</div>

<tr>
<td width="100%">

| 🧩 Component | 📋 Purpose |
|---|---|
| `ftriyana.py` | 🎯 Main entry point |

## 🚀 Quick Start

</div>

<table align="center">
<tr>
<td width="50%">

### 📦 Step 1 — Clone

**git clone https://github.com/BLOODRAVENIST/FTRIYANA.git**

**cd FTRIYANA**

</td>
<td width="50%">

### 🐍 Step 2 — Setup

**python3 -m venv venv**

**source venv/bin/activate**

**pip install -r requirements.txt**

</td>
</tr>
<tr>
<td width="50%">

### 🔑 Step 3 — Configure

**nano config/ai_config.json**

Add your API key inside.

</td>
<td width="50%">

### 🚀 Step 4 — Launch

**python3 ftriyana.py 127.0.0.1**

**That's it. AI drives recon.**

</td>
</tr>
</table>
